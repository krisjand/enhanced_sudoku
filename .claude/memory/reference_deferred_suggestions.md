GitHub issue **#42** ("Deferred suggestions from code reviews") on `krisjand/enhanced_sudoku` tracks SUGGESTION-level review findings that were not resolved before merge.

Each entry in the issue has: PR, file, line, suggestion text.

When a SUGGESTION is not resolved during a review loop, add it to issue #42 instead of leaving an unresolved inline comment that would block the PR.
